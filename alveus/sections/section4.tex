        Sans calcul, déterminer le signe des quotients suivant.
        \begin{enumeratebf}
            \item $A=25 / (-5)$
            \item $B=25 / 5$
            \item $C=(-25) / (-5)$
            \item $D=(-25) / 5$
        \end{enumeratebf}
    Calculer alors ces quotients.
